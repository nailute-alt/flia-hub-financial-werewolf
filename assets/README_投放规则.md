# 04_素材_assets 投放规则

## 本文件夹用途
存放金融狼人杀游戏的所有美术素材，按类型分子目录管理。

## 子目录说明
- `ui/` — UI组件（按钮、面板、对话框、身份牌、投票界面等）
- `characters/` — NPC头像、全身像、角色立绘
- `scenes/` — 场景背景（教室、宿舍、夜晚、白天等）

## 投放规范
1. **格式要求**：
   - 优先 PNG（真透明背景，RGBA）
   - 场景背景可用 JPG（无透明需求时）
   - 禁止使用 WebP（兼容性问题）
2. **命名规范**：`[类型]_[描述]_[版本].png`
   - 示例：`ui_identity_werewolf_v1.png`（狼人身份牌）
   - 示例：`npc_college_student_01_v1.png`（大学生NPC头像）
   - 示例：`scene_classroom_night_v1.png`（教室夜晚场景）
3. **风格要求**：
   - 16-bit像素风，参考《星露谷物语》
   - 浅色背景，阳光明媚（白天场景）
   - 夜晚场景用深蓝/紫色调，但保持像素风统一
   - 人物/动物轮廓留白色描边，透明度100%
4. **尺寸规范**：
   - UI组件：按实际使用尺寸输出，不缩放
   - NPC头像：256×256或512×512正方形
   - 场景背景：1920×1080（16:9）
5. **验收标准**：C（关卡设计师）验收通过后才能投入使用

## 禁止投放
- 设计文档（放 01_设计文档_design/）
- 代码文件（放 03_代码_dev/）
- 截图（放 05_截图验证_screenshots/）
- 废弃/旧版本（移至 _deprecated/ 子目录）
